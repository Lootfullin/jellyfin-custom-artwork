Скачивается только файл ревизии размером в несколько десятков байт. Полный индекс загружается лишь после изменения ревизии.
Во втором режиме Jellyfin должен иметь право записи в папки медиатеки. Существующие постеры и логотипы, созданные не этим плагином, не перезаписываются. Для коллекций всегда используется внутреннее хранилище Jellyfin.
