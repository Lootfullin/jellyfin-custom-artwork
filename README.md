# Cowabunga Custom Artwork для Jellyfin

Плагин подставляет постеры и логотипы из приватного облака Cowabunga вместо
стандартных изображений.

Текущая версия поддерживает Jellyfin 10.11.x. Плагин поставляется одной
платформонезависимой сборкой и работает на любой операционной системе, которую
поддерживает Jellyfin: Windows, Linux, macOS, Docker, Synology и других.

## Как это работает

Windows-агент публикует в облаке два файла:

- `artwork-index.revision.json` — короткая текущая ревизия;
- `artwork-index.v1.json` — полный индекс изображений.

Плагин раз в несколько минут проверяет только ревизию. Полный индекс скачивается
только после изменения ревизии. Каталоги облака никогда не обходятся.

Индекс сопоставляется с локальными фильмами, сериалами, сезонами и коллекциями.
Если у позиции есть TMDB ID, готовое сопоставление хранится по типу медиа, TMDB ID
и номеру сезона.

Начиная со schema v2 официальные коллекции сопоставляются по опубликованному TMDB ID,
поэтому перевод или последующее переименование коллекции в Jellyfin не меняет её
постер. Пользовательские коллекции, которым не соответствует коллекция TMDB,
публикуются со стабильным `collection_key`. Плагин запоминает первое сопоставление с
карточкой Jellyfin, поэтом её последующее переименование не сбрасывает постер. Сайт не
назначает их изображения страницам TMDB.

В стандартном режиме Jellyfin загружает выбранные постеры и логотипы через image
provider и сохраняет их в своём локальном хранилище изображений.

Для коллекций плагин дополнительно проверяет сохранённый файл по SHA-256. Если
Jellyfin или облако временно не завершили загрузку, обновление автоматически
повторяется с увеличивающимся интервалом; уже корректные изображения повторно не
запрашиваются.

Повторная загрузка коллекции не запускает общий конвейер источников Jellyfin:
плагин скачивает только указанный в облачном индексе файл, проверяет его размер и
SHA-256 и напрямую сохраняет в Jellyfin. Ошибка облака поэтому не может подставить
вместо кастомного изображения постер TMDB или другого провайдера.

## Режим хранения

В настройках доступны два взаимоисключающих режима:

- `Хранить в медиатеке Jellyfin` — стандартное поведение remote image provider;
- `Хранить в папке с видеофайлом` — плагин записывает изображения рядом с медиа.

Для отдельного видео используются `<имя видео>-poster.jpg` и
`<имя видео>-clearlogo.png`. Для сериала и сезона — `poster.jpg` и
`clearlogo.png` в соответствующей папке. Коллекции всегда используют внутреннее
хранилище Jellyfin, потому что у них нет папки с видео.

По умолчанию плагин не перезаписывает неизвестные локальные изображения. В режиме
хранения рядом с медиа можно отдельно включить замену существующих локальных
постеров и логотипов изображениями из облака. При возврате во внутреннее хранилище
плагин удаляет только созданные им файлы, если их содержимое с момента загрузки не
менялось.

## Установка через репозиторий Jellyfin

1. Открыть `Панель → Модули → Репозитории`.
2. Добавить репозиторий с любым удобным названием и адресом:

   ```text
   https://raw.githubusercontent.com/Lootfullin/jellyfin-smart-resolver/main/manifest.json
   ```

3. Открыть каталог модулей и установить `Cowabunga Custom Artwork`.
4. Перезапустить Jellyfin.
5. Открыть `Панель → Модули → Cowabunga Custom Artwork`.
6. При необходимости изменить режим хранения и сохранить настройки. Проверка
   индекса запустится автоматически.

Следующие версии можно устанавливать и обновлять через этот же репозиторий.

## Ручная установка

1. Остановить Jellyfin.
2. Удалить старую папку `Cowabunga Custom Artwork_*` из каталога плагинов.
3. Распаковать архив последней версии из GitHub Releases туда же.
4. Запустить Jellyfin.
5. Открыть `Панель → Модули → Cowabunga Custom Artwork`.
6. При необходимости изменить режим хранения и сохранить настройки. Проверка
   индекса запустится автоматически.

GUID плагина сохранён, поэтому Jellyfin воспринимает новые версии как обновление
того же модуля.

## Настройка библиотек

Плагин сам включает `Cowabunga Custom Artwork` в поддерживаемых библиотеках и
ставит его выше остальных источников. Если кастомного файла нет, Jellyfin переходит к
следующему провайдеру, включая Choose your Meta и TMDB.

Локальные `poster.jpg` и другие изображения рядом с медиа имеют приоритет над
удалёнными провайдерами Jellyfin. Если требуется использовать именно Cowabunga,
такие локальные изображения необходимо убрать.

## Безопасность и отказоустойчивость

- поддерживается только HTTPS;
- пути из манифеста проверяются и не могут выходить за папку `Media`;
- размер манифеста и отдельных изображений ограничен;
- при недоступности облака используется последняя корректная локальная копия
  индекса;
- неоднозначные совпадения пропускаются;
- пароль не добавляется в URL и не пишется в лог.
